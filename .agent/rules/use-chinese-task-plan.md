# Task Plan Language Rule

All **Task Plans** (`task.md`), **Implementation Plans** (`implementation_plan.md`), and **Roadmaps** must be written in **Traditional Chinese (繁體中文)**.

This applies to:
- Task lists and checklist items.
- Descriptions and summaries in plans.
- Headers and section titles in plans.

**Exception:**
- Code snippets, filenames, and specific technical terms (e.g., `React Native`, `useEffect`, `VibeCard`) should remain in English or their standard technical format.
